# MyUniMentor website

Static website for https://myunimentor.in

- Pages are plain HTML files in this folder.
- Schools, universities, exams, cities and testimonials live in `data/*.json`.
- After editing a JSON file, run `python3 build.py` to rebuild the pages.
- Logos go in `assets/logos/schools/` and `assets/logos/universities/` (file name = school or university name in lowercase with hyphens, e.g. `olympus-high.png`).
